# Sample images

Images for trying the application and for tests. `bindings/node/test/samples.test.ts` decodes every file listed here.

The values in the tables were measured with `glcm_core`: 8-bit images at `Ng = 256` without quantization, the whole image as the region, and natural-log entropy.

## Synthetic test patterns (`synthetic/`)

These are generated by `scripts/generate-samples.ts`. Regenerate them with `npm run samples`; the output is identical on every run. They contain no third-party material.

| File | Size | Type | Content and expected texture |
| --- | --- | --- | --- |
| `constant-8bit.png` | 128 × 128 | 8-bit gray | Every pixel 128. Contrast and Entropy are 0; the correlations use their fallback value 1. |
| `checkerboard-8px-8bit.png` | 256 × 256 | 8-bit gray | Black and white squares of 8 px. At d = 8, Contrast is 65,025 along 0° and 90° and 0 along 45° and 135°. At d = 16 it is 0 in every direction. |
| `stripes-horizontal-4px-8bit.png` | 256 × 256 | 8-bit gray | Rows alternate between 40 and 215 every 2 px. Contrast is 0 along 0° at every distance, 30,625 along 45°, 90° and 135° at d = 2, and 0 everywhere at d = 4. |
| `stripes-diagonal-8bit.png` | 256 × 256 | 8-bit gray | Bands of 30 and 225, 3 px wide, running along 45°. Contrast is 0 along 45° at every distance. |
| `noise-uniform-8bit.png` | 256 × 256 | 8-bit gray | Uniform noise over 0–255. Entropy ≈ 10.8, Correlation ≈ 0, Contrast ≈ 10,950 in every direction. |
| `two-regions-8bit.png` | 256 × 256 | 8-bit gray | A smooth gradient on the left half and the same uniform noise on the right. Draw an ROI on each side to compare. |
| `quadrants-rgb.png` | 128 × 128 | 8-bit RGB | Red, green, blue and gray quadrants. They convert to the gray values 76, 150, 29 and 128, with a "converted to grayscale" warning. |
| `gradient-16bit.tif` | 512 × 256 | 16-bit gray | A left-to-right ramp plus a vertical ripple, values 0–65,000. Default display window [1272, 63728]. |
| `disc-12bit-in-16bit.tif` | 256 × 256 | 16-bit gray | 12-bit data (800–4000) in a 16-bit TIFF: a smooth background with a noisy disc. Default display window [802, 3959]. |
| `large-4200x4200-8bit.png` | 4200 × 4200 | 8-bit gray | 17.6 megapixels, above the server's raw-transfer limit (4096 × 4096). The viewer uses `display.png` and `/pixel` instead of `/raw`. |

All five are 8-bit grayscale PNGs.

## `lena.jpg`

The original sample of this repository: 650 × 366, 8-bit RGB JPEG, converted to grayscale on loading. It is a crop of the well-known "Lena" test image, which comes from a 1972 magazine photograph. Its copyright status is unclear, and several journals no longer accept it, so prefer `textures/camera.png` for new examples and documentation.
